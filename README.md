# edhus.ru

Статический сайт Эдуарда Хуснутдинова: афиша ноября–декабря 2026 года и прямые ссылки на Ticketscloud.

## Локальный запуск

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

Откройте http://127.0.0.1:4173 . Сборка и установка пакетов не нужны. Шрифты и логотип хранятся локально.

## Источник дизайна

https://web.archive.org/web/20260509191822/https://edhus.ru/

Сохранены оригинальные логотип, Montserrat, чёрно-белая палитра и голубые кнопки афиши. Фотографии Фото1-1.jpg и Фото2.jpg не удалось извлечь из архива; вместо них используется композиция с фирменным логотипом. Исходные HTML и CSS архива сохранены локально в reference/ и исключены из Git.

## GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Сначала проверьте адрес https://ietimakov.github.io/edhus.ru/ . Затем в Settings → Pages задайте Custom domain: edhus.ru и внесите выданные GitHub DNS-записи у регистратора. Не меняйте MX/TXT почты. После проверки домена включите Enforce HTTPS. DNS пока не изменён, файл CNAME намеренно не добавлен до подключения домена.

## Обновление афиши

Карточки находятся в index.html, в секции #concerts. Обновляйте город, дату time[datetime], видимую дату, aria-label и ссылку Ticketscloud вместе. Все семь дат взяты из списка заказчика; время и площадки не добавлены без подтверждения.
